# mixed-precision-densenet

Экспериментальное исследование покомпонентного мультиразрядного (mixed-precision) квантования семейства свёрточных сетей **DenseNet-BC** на наборе **CIFAR-10**. Каждому слою сети назначается собственная разрядность весов и активаций, что позволяет снизить среднюю битность модели при минимальной потере точности классификации.

Полный текст НИР: [`docs/Отчет.pdf`](docs/Отчет.pdf).

## Цель и задачи

**Цель** — разработка и экспериментальная оценка метода послойного мультиразрядного квантования, в котором разрядности подбираются автоматически методом дифференцируемого квантования.

Задачи:

1. Обучение FP32-моделей DenseNet-BC-{52, 64, 76, 88, 100}-12 и оценка их точности.
2. Равномерное квантование после обучения (PTQ) при разрядностях 3–8 бит с дообучением и без.
3. Исследование раздельного назначения битности весам и активациям.
4. Реализация и применение дифференцируемого квантования (DQ, Case U3) для автоматического обучения покомпонентных разрядностей.
5. HAWQ-анализ чувствительности слоёв к квантованию (на основе матрицы вторых производных функции потерь).
6. Сравнительный анализ DQ vs PTQ и сопоставление паттернов разрядностей DQ с результатами HAWQ.

## Применённые методы

- **Равномерное PTQ** с percentile-калибровкой и опциональным fine-tuning (5 эпох).
- **Раздельное PTQ** — асимметричные битности для весов и активаций.
- **Дифференцируемое квантование (DQ)** по параметризации Case U3 из Uhlich et al. (2020): обучаемые `θ = [d, q_max]` с регуляризацией средней битности.
- **HAWQ-анализ** — power iteration (100 итераций, tolerance 1e-3) для оценки топовых собственных значений гессиана послойно.

## Основные результаты

- Покомпонентное DQ-квантование обеспечивает потерю точности **не более 0,33 п.п.** при средней hard-разрядности **~4 бит** для всех пяти моделей семейства.
- При равном битовом бюджете 4 бита DQ превосходит равномерное PTQ с дообучением на **1,16–2,01 п.п.**; для воспроизведения точности DQ равномерному PTQ+FT требуется на 0,97–1,42 бит больше на каждый квантователь.
- Битность **весов** является доминирующим фактором: активации менее чувствительны к снижению разрядности.
- Внутри плотных блоков чувствительность весов возрастает с позицией слоя и локализуется в **bottleneck-свёртке Conv1×1** — единственном компоненте BC dense layer с расширяющимся конкатенированным входом.
- Ранние плотные блоки допускают более агрессивное сжатие, чем поздние, благодаря обучаемым преобразованиям после блока, гасящим ошибку квантования при совместной оптимизации.
- Структурные блоки (`conv0`, переходные слои, классификатор) требуют повышенной разрядности 5–7 бит — это независимо обнаруживается и DQ, и HAWQ.

## Рекомендации по применению

1. Для DenseNet-BC основной метод квантования — **DQ Case U3** с целевой средней разрядностью 3 бита и инициализацией квантователей в 4 бита; ожидаемый итог — ~4 бит/слой при потерях <0,35 п.п.
2. Если DQ недоступен, использовать **равномерное PTQ при 5 битах с 5-эпоховым дообучением** (потери в пределах 0,5 п.п.). Раздельное PTQ преимуществ при равном среднем бюджете не даёт.
3. Резервировать повышенную разрядность (5–7 бит) для первого свёрточного слоя, переходных слоёв и классификатора; веса плотных слоёв допускают сжатие до 3 бит при условии дообучения.
